# Лазур — футбол Полтавщини

Односторінковий новинний сайт про футбол Полтавщини: React 19, TypeScript, Tailwind CSS v4, shadcn/ui (Radix), wouter. Збирається в статичні файли для GitHub Pages і пререндериться в HTML для пошукових систем.

## Запуск

```bash
npm ci
npm run dev        # http://localhost:5173
npm run build      # typecheck → клієнт → SSR → пререндер у dist/
npm run preview    # перегляд зібраної версії
```

## Публікація на GitHub Pages

1. Завантажте проєкт у репозиторій на гілку `main`.
2. **Settings → Pages → Source: GitHub Actions**.
3. Workflow `.github/workflows/deploy.yml` збере сайт і викладе його. Він сам передає шлях підпапки (`/назва-репозиторію`) та адресу сайту, тож у HTML з’являться правильні посилання, `canonical`, `sitemap.xml` і `robots.txt`.

Збирати вручну для підпапки: `PRERENDER_BASE=/repo SITE_URL=https://user.github.io/repo npm run build`.

## Як влаштовані шляхи

- `vite.config.ts` → `base: "./"`: усі ресурси підключаються як `./assets/...`, тож одна збірка працює в корені домену, у підпапці й на власному домені.
- `src/lib/base-path.ts` визначає підпапку під час роботи за адресою власного скрипта (`<base>/assets/…`) і передає її в `<Router base>` wouter.
- Розділи мають власні адреси: `/vorskla`, `/sk-poltava`, `/hirnyk-sport`, `/match-tsentr`, `/tablytsi`, `/premier-liha`, `/persha-liha`, `/druha-liha`, `/kubok-ukrainy`, `/ostanni-novyny`, `/facebook`, `/kontakty`. Пряме відкриття такої адреси працює через `404.html` (копія головної сторінки), після чого сторінка прокручується до розділу, а адреса ліги відкриває потрібну вкладку таблиці.
- Якщо сторінку відкрито в іншій підпапці, ніж та, для якої її пререндерили, застосунок не гідратує HTML, а рендерить його заново, тож посилання завжди правильні.

## Де що змінювати

Усі дані лежать на початку `src/App.tsx`:

| Масив | Що містить |
| --- | --- |
| `SITE` | назва, редактор, пошта, посилання на Facebook, тексти блоків |
| `CLUBS_DATA` | клуби: ліга, статус, герб (`crestBg`, `crestText`, `crestShape`), стадіон, сайт |
| `ARTICLES_DATA` | матеріали: `placement` = `lead` (головне), `grid` (картки розділу), `more` (відкриваються кнопкою «Всі новини розділу»), `wire` (лише в «Останніх новинах») |
| `MATCHES_DATA` | матчі для рядка рахунків (`ticker: true`), матч-центру й Кубка; статус `live` показує хвилину й золоту позначку «Наживо» |
| `STANDINGS_DATA` | рядки таблиць; очки й кількість ігор рахуються з перемог, нічиїх і поразок |
| `TABLES_META` | підписи, джерела й зони таблиць |

**Перед запуском** замініть `SITE.editor`, `SITE.email` і `SITE.facebookUrl` на справжні дані видання.

**Меню.** Поле `navLeague` у клубу визначає, у якому випадному меню він показаний. СК Полтава після вильоту з УПЛ у 2026 році стоїть у «Першій лізі»; щоб повернути схему конкурента, поставте `navLeague: "premier-liha"`.

Жирний текст у будь-якому абзаці пишеться як `**так**` і перетворюється на `<strong>` функцією `formatText` (`src/lib/format.tsx`).

## Дані станом на 12 жовтня 2026

Таблиці, результати й розклад взято з офіційних сторінок ПФЛ (Перша ліга, Друга ліга, група Б) та публікацій про таблицю УПЛ після 8-го туру. Форма команд Першої ліги відновлена з календаря ПФЛ і звірена з офіційною таблицею. Тексти новин написані для цього сайту на основі цих даних.

## Шрифти

Cinzel і Plus Jakarta Sans не мають базової кирилиці. Для українських літер підключено Cormorant SC (заголовки) та Inter (інтерфейс); латиниця й цифри лишаються у фірмових шрифтах, Lora покриває кирилицю сама. Усі шрифти вбудовані в збірку через `@fontsource`, без зовнішніх запитів.

## Структура

```
src/
  App.tsx                 дані + композиція сторінки
  main.tsx, entry-server.tsx
  index.css               токени Tailwind v4, змінні shadcn, текстура лазуриту
  lib/                    formatText і дати, маршрути, визначення base path
  hooks/                  scroll-spy, висота шапки, media query
  components/ui/          button, badge, card, tabs, sheet, dropdown-menu
  components/site/        шапка, герой, матч-центр, розділи клубів, таблиці, стрічка, Facebook, футер, зміст
scripts/prerender.mjs     пререндер, 404.html, robots.txt, sitemap.xml
```
